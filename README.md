# 🛒 نظام رماح كاش (Rammah Cash POS)

نظام إدارة مبيعات ونقطة بيع (POS) يعمل بالكامل على المتصفح بدون الحاجة إلى خادم خلفي (Serverless / Client-Side Only)، ويعتمد على `localStorage` لحفظ البيانات.

## 🌟 الميزات الرئيسية
- **نقطة البيع (POS):** واجهة سريعة للبحث وإضافة المنتجات للسلة وإتمام المبيعات.
- **إدارة المخزون:** إضافة وتعديل المنتجات، متابعة الكميات المتاحة، وسعر التكلفة والبيع.
- **تتبع رأس المال الآلي:** يمثل رأس المال القيمة الإجمالية للمخزون المتاح بسعر التكلفة، وينقص تلقائياً عند البيع ويزداد عند المرتجعات أو الشراء.
- **التقارير المالية:**
  - إحصائيات إجمالية (المبيعات، التكلفة، صافي الأرباح).
  - تجميع الأرباح اليومية والأسبوعية (من السبت إلى الجمعة).
  - سجل تفصيلي للفواتير مع إمكانية إلغاء/إرجاع الفاتورة.
- **النسخ الاحتياطي:** تصدير واسترجاع بيانات النظام بصيغة JSON.

## 🛠️ التقنيات المستخدمة
- HTML5 / CSS3 (Tajawal Font + FontAwesome)
- Vanilla JavaScript (ES6+)
- LocalStorage API
